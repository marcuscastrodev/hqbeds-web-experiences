# Case study methodology and permissions

These case studies reference publicly accessible HQBeds web pages that Marcus Castro identified as part of his development portfolio.

## What this repository includes
- Links to original published pages.
- High-level summaries of page goals and observable user-facing structure.
- Notes on technical and UX questions that need confirmation.

## What this repository does not include
- HQBeds source code, private credentials, internal analytics, unpublished creative assets, or client data.
- Claims of conversion uplift, implementation details, or authorship beyond currently supplied evidence.
- Screenshots until their suitability for reuse has been checked.

**Important:** public availability of a webpage does not automatically grant permission to redistribute its code or imagery. Ask HQBeds for permission where necessary.
